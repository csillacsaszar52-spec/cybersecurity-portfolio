# Csilla Csaszar — Cybersecurity Portfolio

A responsive portfolio built with HTML, CSS, and JavaScript.

## Preview locally

Serve the folder with any local static server and open `index.html`. For example, run `npx serve .` from this directory. No build step is required; using a server allows the browser to load the local Three.js module.

## Update later

- Add future case studies inside the `#projects` section of `index.html`.
- Keep public artifacts sanitized: remove personal contact details, internal addresses, credentials, and sensitive metadata.
- Replace lab-summary cards with full case studies as reports become available.

## Privacy

The public site intentionally excludes phone number and email address. LinkedIn is the only public contact method.
